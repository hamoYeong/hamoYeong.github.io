# Posts 후속 소재

## 탁구 초보를 가르치며 배운 교정과 반복 설명

상태: 후속 인터뷰와 사용자 직접 작성이 필요한 소재. 공개 Post로 만들지 않음.

### 핵심 논지

초심자의 막힘은 한 번의 설명으로 사라지지 않는다. 시작하지 못하는 지점과 이미 굳어진 습관을 구분하고, 오래 관찰하면서 같은 원리를 다른 표현과 작은 교정으로 반복해야 한다. 이 경험은 소프트웨어 초심자에게 발판의 크기와 설명 순서를 조정하는 현재의 관심과 연결된다.

### 사용할 수 있는 경험

- SCUTTA 훈련부장으로 탁구를 처음 배우는 사람과 잘못된 습관이 굳은 사람을 주로 도왔다.
- 초심자가 왜 시작하지 못하는지, 어느 동작에서 막히는지 관찰했다.
- 같은 내용을 한 번에 이해시키려 하기보다 여러 방식으로 반복 설명했다.
- 굳어진 습관은 한 번의 설명으로 바뀌지 않아 오래 관찰하고 작은 변화를 반복했다.
- 이후 화학 튜터링, C4의 1:1 학습 지원과 C5의 발판 설계에서 상대의 이해 단계와 설명 순서를 조정하는 관심으로 이어졌다.

### 추가로 사용자가 직접 답해야 할 질문

- 처음 배우는 사람과 잘못된 습관이 굳은 사람의 막힘을 어떻게 다르게 알아차렸는가?
- 같은 내용을 다르게 설명했던 공개 가능한 구체적 예시는 무엇인가?
- “작은 변화”라고 판단한 행동은 무엇이었고, 얼마나 오래 관찰했는가?
- 설명을 반복하는 것과 학습자가 스스로 감각을 찾게 기다리는 것의 경계를 어떻게 정했는가?
- 효과가 없었던 설명이나 교정 방식은 무엇이었는가?
- 탁구의 신체 동작 학습과 프로그래밍의 개념 학습을 연결할 때 같다고 말할 수 없는 부분은 무엇인가?
- 이 경험을 회고하는 사용자의 감정과 말투가 드러나는 장면은 무엇인가?

### 공개 전 주의

- 특정 부원을 식별할 수 있는 이름, 시기, 대화와 경기 기록을 쓰지 않는다.
- 반복 설명이 일반적인 교육 효과를 냈다고 주장하지 않는다.
- 탁구 지도 경험을 소프트웨어 교육 전문성으로 바로 등치하지 않고, 관찰과 발판 조정에 대한 근거 경험으로만 연결한다.
